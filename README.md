# 📂 Projects

## 1️⃣ Network Vulnerability Assessment using OpenVAS

### Objective

To perform a complete network vulnerability assessment using OpenVAS and identify security weaknesses in a controlled lab environment.

### Tools Used

- OpenVAS
- Ubuntu
- VirtualBox

### Activities Performed

- Installed and configured OpenVAS on Ubuntu.
- Created scanning targets for vulnerability assessment.
- Performed authenticated and unauthenticated network scans.
- Identified:
  - Missing security patches
  - Exposed services
  - Security misconfigurations
  - Outdated software
- Reviewed vulnerability severity using CVSS.
- Documented remediation recommendations.

### Skills Gained

- Network Vulnerability Assessment
- Vulnerability Reporting
- CVSS Analysis
- Risk Prioritization
- Security Documentation
