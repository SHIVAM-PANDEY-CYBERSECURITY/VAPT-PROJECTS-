# 🚀 Project 1 – Network Vulnerability Assessment using OpenVAS

## Overview

This project demonstrates the process of identifying security vulnerabilities in networked systems using **OpenVAS (Greenbone Vulnerability Management)**.

The lab covers the complete vulnerability assessment lifecycle, including installation, target configuration, vulnerability scanning, report analysis, and remediation verification.

### Key Activities

- Installing OpenVAS
- Configuring vulnerability scanner
- Creating scan targets
- Running vulnerability scans
- Reviewing scan reports
- Identifying critical findings
- Applying remediation
- Re-scanning systems

### Skills Gained

- Vulnerability Assessment
- Linux Administration
- Risk Analysis
- CVSS Interpretation
- Security Reporting

**Tools Used**

- Ubuntu
- OpenVAS
- VMware Workstation

# 🌐 Project 2 – Web Application Vulnerability Assessment using OWASP ZAP

## Overview

This project focuses on identifying security issues in web applications using **OWASP ZAP (Zed Attack Proxy)**.

It demonstrates how to intercept web traffic, perform passive and active scans, analyze vulnerabilities, and generate professional security reports.

### Key Activities

- Installing OWASP ZAP
- Configuring Browser Proxy
- Capturing HTTP Requests
- Passive Vulnerability Scanning
- Active Vulnerability Scanning
- Reviewing Security Alerts
- Generating Reports

### Skills Gained

- Web Application Security
- HTTP Traffic Analysis
- Security Testing
- Vulnerability Analysis
- Risk Assessment

**Tools Used**

- OWASP ZAP
- Firefox
- Google Chrome
- DVWA
- VMware Workstation

# 🖥️ Project 3 – Patch Management & Vulnerability Remediation using WSUS

## Overview

This project demonstrates how Windows updates can be centrally managed using **Windows Server Update Services (WSUS)**.

The objective was to understand enterprise patch management by configuring a WSUS server, deploying updates to client machines, and verifying update compliance.

### Key Activities

- Installing WSUS
- Configuring Synchronization
- Creating Update Policies
- Configuring Group Policy
- Approving Security Updates
- Deploying Updates
- Monitoring Update Status
- Generating Compliance Reports

### Skills Gained

- Windows Server Administration
- Patch Management
- Vulnerability Remediation
- Group Policy
- Endpoint Management

**Tools Used**

- Windows Server 2016
- WSUS
- Windows 10
- VMware Workstation
